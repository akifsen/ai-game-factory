# V0.8-8 multi-clip animation review checkpoint

The multi-clip review feature is approved after independent source review and
acceptance checks. It consumes two to eight current V0.8-6 packages from one
evidence lineage, preserves caller order and source bytes, and publishes
thirteen root files plus two original files per numbered clip slot. See the
[usage guide](../guides/v0.8-8-multi-clip-animation-review.md).

One character, skeleton, and player serve the selector. Selecting a valid clip
pauses playback, resets bone poses, and seeks to zero while preserving session
speed and loop settings. Authored animations remain immutable. The public
V0.8-6 currentness authority supplies three checks per source during export
and one during currentness. Exact source snapshots and a collection pin detect
drift across those checks. The staged tree must match captured expected bytes
before fresh atomic publication. Identical shared source bytes are reused in
memory; manifests and directory inventories have explicit bounds.

Independent Lead verification on Windows:

- The revised 38-case unit run was **37 passed / 1 failed**, 844.20 seconds,
  with no skips. The sole failure was a test expecting a coherently modified
  bone scene to pass the public V0.8-6 gate. That gate correctly returned false.
  The test expectation was corrected; its independent rerun passed in
  56.74 seconds. This is not reported as an uninterrupted green 38-case run.
- The unit run passed the actual eight-source upper boundary: eight real
  public V0.8-6 exports, ordered 29-file output, currentness, original source
  byte preservation, and shared GLB object identity across all eight captures.
- Actual Blender/Godot integration passed in 193.40 seconds, with no skips.
  It created two authored packages from the same evidence, exported the set,
  launched and inspected consumer copies, checked clip switching and disjoint
  weighted deformation, rejected coherent nested tamper, and preserved
  original source/output bytes.
- All four applied files matched the reviewed isolated files after newline
  normalization. Five critical applied-tree unit checks passed in 175.18
  seconds; the applied real integration passed in 192.40 seconds, with no skips.
  These runs explicitly asserted the primary source and resource origins.
- Ruff passed for `src` and `tests`; 273 files satisfied the formatter.
  Mypy passed for all 134 source files. Independent review found no remaining
  concrete source or test blocker after the final correction.

The first unit attempt was 21 passed / 11 failed. Source error-boundary and
manifest uniqueness findings were fixed, and mutating tests were isolated
from shared fixtures before the final verification. An initial applied-test
command loaded an ambient editable package from the temporary checkout; it
was discarded as applied-tree evidence and rerun with explicit primary paths.

The existing quick/full CI time budgets increased to 65/80 minutes based on
the previously measured runtimes plus this feature's additional acceptance
work. Job selection, matrix, and installed-unit shards remain unchanged.
No Actions dispatch or retry was used for this slice.
