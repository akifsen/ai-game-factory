# V0.8-6 authored animation clip checkpoint

This test-only development slice consumes a current V0.8-4 character preview and
an explicit local `rig-animation-clip-0.8.0` JSON file. It preserves the original
clip bytes and SHA, verified GLB, capsule scene and upstream metadata, and exports
a deterministic ten-file Godot package. Production and promotion eligibility
remain false; public `rigged_character` support remains unavailable.

The closed clip contract supports up to eight rotation tracks and 64 keys per
track, with finite normalized quaternions, strictly increasing key times and
explicit duration/loop fields. Animated bones must have positive finite weights
in the verified GLB. The exporter derives the weighted names from skin joint
slots and binds them, together with the original clip SHA, into the scene.
Godot builds the AnimationPlayer tracks from the authored data.

The generic parser accepts durations greater than zero and at most ten seconds.
The Godot adapter rejects durations below 0.001 seconds before staging, because
the pinned engine otherwise silently raises the animation length to 0.001.
The source JSON and key times are never rewritten or rescaled.

Publication checks fresh evidence, upstream preview and original clip bindings
before staging, before publication and after publication. Currentness rebuilds
canonical expectations from those authorities. Rehashed package files cannot
replace the original source. If the original source changes after atomic
publication, export fails and the immutable published directory may remain as a
stale orphan; it is not deleted or treated as current.

Independent Lead verification of the isolated implementation on Windows:

- The complete 45-case unit run passed 43 cases in 707.36 seconds. Two test-only
  errors were corrected: a duration mutation that invalidated its own last key,
  and a GLB race assertion expecting the wrong typed error. Both corrected
  cases then passed independently in 52.37 seconds. All 45 case identities were
  therefore verified across the full run and the targeted correction run.
- Real Blender 5.2 / Godot 4.7.2 integration passed with zero skips in 129.61
  seconds. Godot consumed the exporter-produced player unchanged. It verified
  the 1.5-second authored clip, actual weighted deformation and fixed control,
  capsule/root/bone invariants, the exported 0.001-second clip, and wrong-track,
  changed source-SHA and closed-shape negatives.
- Applied files matched the reviewed isolated files after newline normalization.
  Repository-wide Ruff check/format passed for 266 Python files, and mypy passed
  for 132 source files.
- After applying the patch, 32 focused tests passed in 52.80 seconds (the 29-case
  foundation plus weighted-bone and corrected behavior checks). The real-tool
  integration passed again with zero skips in 128.70 seconds.

The foundation was separately committed as `279782d`; its 29 tests and independent
review passed. Antigravity quota was unavailable, so implementation and revisions
used the required Cursor fallback. Lead and independent reviewer accepted the
code after reviewing its source and actual validation results.

This checkpoint does not claim Linux actual-tool proof, a published release or
completed final-source CI. The frozen 425-case candidate inventory, reviewed
pins and existing preview APIs are unchanged. No paid provider, retargeting,
root motion, IK or gameplay controller is included.
