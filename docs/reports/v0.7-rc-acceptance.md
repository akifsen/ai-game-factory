## Negative cases and integrity

The public character journey covers missing or changed captures, a mismatched
profile pin, and a newer FAILED Godot attempt. Completed export/report queries
reject drift without running production again or falling back to older evidence.
Read-only SQLite access may create normal WAL/SHM auxiliary files; this is
qualified explicitly in the operator guide and acceptance checks.

Two fresh public character runs using this same wheel produced identical model
bytes and all nine capture hashes. The snapshot records the compared pins. This
is a bounded fixture result, not a claim that every Blender export is byte
deterministic. API negative tests intentionally leave a newer FAILED attempt;
the comparison concerns the immutable published bundles.

The acceptance driver has independent review approval and **85 passing unit
tests**. It clears pytest filters and live provider credentials, requires an
actual wheel and computed digest, rejects skipped or empty required suites,
allocates an exclusive contained run directory, emits a fresh FAIL report on
preflight failure, and preserves older reports. Windows drive-relative and
reserved run IDs are rejected. Diagnostic subsets cannot satisfy its release
gate.

The installed application also passed **219 V0.6/V0.7 contract tests**. These
frozen legacy tests were run from the checkout because their fixture data paths
are relative; the application imports still came from the installed wheel.
The frozen V0.6 test and dataset are unchanged. Ruff checked the full source,
tests, and scripts; all 222 Python files were formatted. Mypy passed all 102
source files including the acceptance driver.

## Earlier attempts and final source checks

Earlier failed verification attempts are retained locally. A shared pytest
temporary directory was inaccessible; a private temporary root resolved it.
One test-authoring namespace import failed under `python -I`; explicit sibling
loading resolved it, and the final full installed run passed.

An initial broad source integration run recorded 402 passes, 11 skips, and two
failures. The legacy real-engine tests required access to the local Windows
certificate store, an external workspace, and an installed application for the
crash wrapper. With those conditions supplied, both passed against the fresh
wheel. The final full source run then passed **1,647 tests**, with **15 skips**
and zero failures in 815.46 seconds. The skipped cases comprise eleven requiring
Windows symlink privileges, three Linux/POSIX cases, and one additional opt-in
contaminating-Python fixture. They are not claimed as executed coverage.
The separate required installed V0.7 gate passed without any skips.

## Remaining release gates

The CI workflow is wired to the actual built wheel and digest, uses an external
working directory, and archives each installed acceptance run. Local YAML and
argument checks passed; remote execution has not been verified.

The remaining gates are authorized push of the final checkpoint, the Linux
Python matrix and real rendered Blender/Godot CI on that source identity, and
the final cross-platform engineering decision. The package remains a release
candidate. Rigged characters, animation, and provider-generated assemblies stay
unsupported.

All development approvals name isolated fixture actors. No live paid submission
or production database mutation was made. A fake cost of five `fake_credits`
exercises accounting; it does not consume provider credits. Human concept,
paid-operation, and final visual decisions remain required for production.
