# V0.8-10a review session handoff checkpoint

The read-only workflow exports exactly `review-report.json` and `review-report.md` from a validated durable session. Reports retain the bound clip order, exact JSON annotations, revision and raw session SHA, review-set digests, currentness and false eligibility flags. Markdown renders untrusted fields as literal text and displays a historical warning for stale sessions. Output bytes are deterministic across fresh destinations and each file is bounded to 128 KiB.

Publication uses the existing atomic no-overwrite container helper and owned staging. Destination and staging paths cannot overlap canonical source or session paths; a legitimate shared parent remains allowed. Raw session checks reject a writer change during authority evaluation or payload I/O. Failures clean only owned stages and preserve existing output or a competing writer's publication.

Independent Team Lead verification after application passed all 23 fast tests in 35.58 seconds. Ruff, formatting and focused mypy passed. Coverage includes nonalphabetical clip order, complete annotations, source/session preservation, determinism, stale and removed-source history, malformed/oversized sessions, invalid status/bookmarks, late writer conflicts, reserved/overlapping output paths and owned-stage cleanup. Currentness gates are stubbed in this fast suite; these results do not claim actual Blender/Godot or unmocked public-gate acceptance.

Public-gate integration, actual saved UI-session handoff acceptance and installed-wheel qualification remain subsequent gates. This checkpoint adds no CI jobs, dispatches, approval mechanism or promotion behavior. See the [handoff API guide](../guides/v0.8-10-review-session-handoff.md).
