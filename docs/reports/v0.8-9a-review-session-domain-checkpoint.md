# V0.8-9a review session domain checkpoint

This checkpoint implements the domain model only. Durable storage, live review-set currentness, the command bridge, and the Godot session interface remain separate work.

The immutable session binds an ordered two-to-eight-clip V0.8-8 review set to its review root, raw manifest digest, root payload digest, and global nested clip payload digest. Each clip also records its raw clip digest and duration. Review records contain only `unreviewed`, `keep`, or `revise`, a note of at most 2 KiB of UTF-8, and at most 32 unique finite bookmarks within that clip's duration. `keep` does not approve production or promotion; both eligibility flags remain strictly false.

Creation, parsing, document conversion, serialization, and mutation validate their public inputs, including directly constructed dataclasses. The canonical JSON document is limited to 64 KiB. Each successful operation increments the revision and preserves other clips and the binding. Numeric durations and bookmarks encode consistently as floats, so valid integer-valued inputs survive a parse-and-serialize round trip without changing canonical bytes.
