sınırları korundu. DAG: `godot_execute → godot_validate → record_evidence`.

çekirdeğe motor bağımsız aktarır. Godot staging, argv ve journal yorumlama adaptör

scenario/observation schema **0.2.0**. [ADR 0005](../adr/0005-godot-staging-and-independent-oracle.md).

Senaryo sınırları: 256 KiB input, 10.000 tick, 256 action/snapshot/assertion,
her import/runtime için en fazla 120 saniye. Boş assertion kümesi, unknown field/action,
duplicate JSON key, NaN/Infinity, bool-as-integer ve güvensiz scene yolları reddedilir.

Sonraki tick'lerde frame sonu checkpoint'i, sıralı action ve snapshot uygulanır.

Runtime request assertion/expected içermez; tam oracle ayrı kalıcı snapshot'tadır.
Observation execution/scenario/fingerprint, bütün snapshot'lar ve COMPLETED işaretiyle bağlanır.

## Approval Safety:

Process izni veya managed-write policy onayı gerektiğinde workflow BLOCKED olur;
onaydan önce execution/process artifact yoktur. Yeni CLI sürecinde approve/resume
gerçek Godot'u çalıştırdı. Tamamlanmış resume yeni execution eklemedi. Kaynak değişince
eski onay kullanılmadı, yeni approval ID oluştu ve dispatch yapılmadı.
Senaryo/source/executable/harness fingerprint'i yeniden kontrol edilir.

## Timeout / Recovery:

Gerçek `_ready` içinde sonlu 2,5 saniye bekleme; runtime timeout 1 saniye.
Kaydedilen süre **1.687 s**, `timed_out=true`,
`cleanup_completed=true`. Exit code 0 olsa bile
timeout workflow'u FAIL yaptı. Timeout/hata logları korundu.

Kontrollü fault injection yalnız test helper'ında gerçek runtime sonrasında uygulandı:
terminal receipt yoksa yeni CLI süreçlerinde tekrar resume/retry UNCERTAIN/BLOCKED;
terminal journal kalıcıysa recovery güvenli FAILED, açık retry yeni attempt ve gerçek
PASS üretir. Eski attempt ve journal korunur. PID'e dayanarak yabancı süreç öldürülmez.
[Gerçek kesinti/kurtarma kabulü](v0.2-recovery-acceptance.json).
Ücretli/metered conservative task'lar terminal process kanıtıyla otomatik güvenli retry'a düşmez.

## Stale-Evidence Protection:

Kaynak §16'daki sekiz durumun regresyonu vardır: eski attempt raporu yeni attempt'e
kopyalama, doğru scenario/yanlış execution, COMPLETED ama eksik snapshot, PASS metni
ama nonzero exit, exit 0 ama rapor yok, validation öncesi artifact değişimi, raporun
kendi expected/actual PASS alanları ve yönetilen alan dışı rapor yolu.
Malformed/truncated çıktı da başarısızdır. Artifact hash ve güncel attempt filtreleri
bağımsız doğrulanır. Bu, kötü niyetli yerel oyuna karşı kriptografik attestation değildir.

## Known Limitations:

- Güvenilen yerel oyun kodu kullanıcı yetkisiyle çalışır; staging OS sandbox değildir.
- Secret/cache dışlaması tanımlı isim/yol kurallarıdır, genel içerik sınıflandırıcısı değildir.
- Linux runtime ve uzak CI henüz doğrulanmadı; POSIX detached session'lar owned process group dışında kalır.
- Host file-symlink yetkisi yok; dört ilgili test atlandı. Windows junction testleri çalıştı.
- Belirsiz canlı-child durumu otomatik tahminle çözülmez; manuel inceleme gerektirir.
- Integer fixture sözleşmesi; genel fizik determinismi, görsel kalite, AI oyuncusu veya export doğrulaması değil.
- Meshy, gerçek ücretli provider, Blender işleme, vision/screenshot/audio/web/V0.3 eklenmedi.
- Remote publish, release, push veya commit yapılmadı.
