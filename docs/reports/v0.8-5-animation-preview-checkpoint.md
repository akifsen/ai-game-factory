# V0.8-5 animation preview checkpoint

V0.8-5 adds a test-only animation preview export on top of the current V0.8-4
character preview and live engine-finalized C2-B evidence. The development package
version is `0.8.0rc2`; the previously published rc.1 release stays immutable.

The exporter preserves the upstream GLB, capsule scene and metadata bytes, then
publishes a separate deterministic package with a closed `rig_smoke_01` clip.
The scene starts a real Godot AnimationPlayer/AnimationLibrary rotation track on
`LeftUpperArm`: a one-second loop with 0°, 20° Y and 0° keys at 0, 0.5 and 1 seconds.
Currentness independently checks canonical package contents against fresh live
readiness and the upstream preview. Rehashed modified files cannot establish
authority. Publication is atomic and does not overwrite existing destinations.

The Godot consumer loads the capsule-bearing `character.tscn`, checks the actual
track target and keys, pauses before exact seeks, and bakes mesh vertices at both
times. Fixed affected and unaffected regions establish real deformation while
root, model and capsule transforms, capsule dimensions and the 12 bone names
remain unchanged. Inspection requires the real compatibility renderer; import
alone may use headless mode. Consumer import occurs on a separate package copy.

Independent local verification on Windows / Python 3.12:

- 41 unit tests passed, zero skips, in 582.60 seconds.
- One fresh Blender 5.2 / Godot 4.7.2 integration passed, zero skips, in 136.10
  seconds. It includes wrong weighted, unweighted and nonexistent bone negatives,
  and a misrouted actual track with a canonical specification.
- The direct rendered diagnostic measured affected displacement 0.13703911 m
  and unaffected displacement 0 m; the full integration enforces fixed bounds.
- 35 release metadata / CI-helper tests passed in 23.39 seconds.
- Both preview and animation real-tool integration tests passed from the installed
  rc.2 wheel outside the checkout: two passes, zero skips, in 255.25 seconds.
  The isolated import probe confirms `site-packages` origin and matching
  `0.8.0rc2` module and distribution versions.
- Ruff check and format passed for 261 Python files; mypy passed for 129 source files.

Unit coverage includes missing/stale upstream previews, newer evidence attempts,
source/spec/profile/revision/receipt drift, deterministic fresh exports, original
byte preservation, coherent scene/spec/manifest rehashes, strict numeric types,
file growth after size preflight, and unsafe/existing destination guards.
Nonmutating tests share completed evidence and copy canonical packages; mutation
cases use independent managed workspaces. No readiness result is cached between
public API calls and the frozen 425-test candidate inventory stays unchanged.

Lead and independent reviewer approve this implementation. Exact-head natural CI
remains a separate release verification step; this report does not claim that
the pending CI step passed or that rc.2 is published.
The prior V0.8-4 merge `d2110f5` passed all 24 required natural main CI jobs.

No paid provider, retargeting, root motion, IK, gameplay controller or production
promotion is included. Public `rigged_character` remains unsupported and every
export keeps `production_eligible=false` and `promotion_eligible=false`.
