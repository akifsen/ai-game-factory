# V0.7 standalone geometry validation

Decision: **APPROVED for the standalone geometry slice**. Advanced profiles
remain unavailable until workflow, runtime, evidence and release gates pass.

The typed V0.7 validator decodes a bounded GLB snapshot once and shares a frozen
context across closed, ordered rule functions. Assembly topology, pivot bases
and motion axes, socket ancestry and placement, single-mesh contracts, and box
or capsule policies are selected by capabilities rather than profile names.
Source-to-processed comparison verifies the declared root normalization and
preserves local semantic transforms and oriented LOD0 triangle geometry. It
does not authenticate provenance or establish authored semantic correctness.

The Team Lead independently ran 311 profile, contract, geometry, facade,
forbidden-content and frozen legacy golden tests; all passed in 3.52 seconds.
The log is `.verification/geometry-root-full.log`. Targeted Ruff and mypy
checks passed. Independent review approved the final geometry implementation.

Review found and corrected greedy tolerance matching that falsely rejected a
valid two-triangle correspondence. Matching now builds a spatially bounded
candidate graph and finds augmenting paths without recursion, with explicit
comparison and path-work limits. A global exact-multiset fast path handles
identical repeated triangles without generating that graph. Regressions cover
ambiguous alternatives, input ordering, missing perfect matches and repeated
triangles. Exceeding work bounds fails closed; arbitrary adversarial geometry
is not guaranteed to be accepted merely because some correspondence exists.

No paid request, database migration, workflow activation or advanced profile
availability is introduced by this slice. Existing ordered V0.6 findings remain
covered by the frozen authoritative golden suite.
