# V0.7 static character Godot runtime proof

## Scope

This slice adds a standalone Godot check for exact-bound `AssetSpecificationV07` / `AssetProfileV07` static `provider_generated` single-mesh characters. It preflights the pinned raw and processed GLBs, imports the processed GLB in a new project, verifies its LOD inventory and transforms, creates the declared capsule collider, performs a physics ray query, evaluates every declared review view, and retains the actual rendered PNGs. It does not call a provider, create workflow/database rows, or make approval decisions.

Character profiles must explicitly request front, rear, left, right, and three-quarter views. The adapter also accepts every view in the shared camera-placement contract; focused tests exercise that complete set. Numeric observations are strict: non-finite or unrepresentably large numbers, booleans in numeric vectors, invalid surface counts, and mismatched collider/camera/binding observations cannot produce PASS.

The request binds the workflow/revision/asset/execution/attempt, raw and processed hashes, canonical profile and specification hashes, and the packaged runtime-harness hash into a canonical request digest. The observation echoes and is checked against those bindings even on a controlled FAIL. Staged GLB, request, and harness bytes are rechecked both before dispatch and after Godot exits. Outputs are attempt-specific and captures are decoded and checked before PASS is returned.

Executed with Godot 4.7.2 at `C:\Users\lenovo\devel\godot\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe`:

```powershell

```

Result: **19 passed**. Integration has four cases: three real Godot invocations (both capsule-origin policies and a fresh real Blender `CharacterProcessor` → Godot composition run, each with all five required review renders) plus one strict-JSON-only case. The Blender composition retains and rechecks the raw source hash. Positive Godot observations are independently mutated to prove forged position/basis/scale, capsule, ray, camera, and stale-binding values are rejected; strict JSON cases reject overflowing numbers. Unit coverage rejects area-body/area-required profiles and profiles that do not require a physics ray before engine dispatch.

Ruff and mypy passed. Pytest emitted an environment warning because it could not write the repository `.pytest_cache`; tests used the explicit `.verification` basetemp and completed successfully.

## Limits

This verifies a small single-mesh fixture and one real Blender-processed source, not a production content corpus, installed-wheel journey, all GPU/renderer combinations, or end-to-end approval/export workflow. Godot renders with the configured headless compatibility backend. Real Godot and Blender integration coverage skips when the corresponding test executable is unavailable.
