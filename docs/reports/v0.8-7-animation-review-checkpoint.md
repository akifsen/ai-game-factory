# V0.8-7 animation review checkpoint

This development slice adds interactive Godot review of an authored animation,
and a readiness-gated Python exporter and currentness API. Play, Pause, Restart,
timeline seeking, elapsed time, session loop and four playback speeds use an
ephemeral copy of the source Animation. See the [review guide](../guides/v0.8-7-animation-review.md).

The exported package contains exactly thirteen files: all ten original V0.8-6
files unchanged, the review scene and controller, and a deterministic manifest.
The upstream public currentness API remains the readiness authority. Export
checks it at three publication barriers; review currentness checks it once.
Captured upstream bytes must agree before and after each gate. Canonical packaged
UI resources and the complete staged tree are checked before atomic publication
into a fresh destination. Export neither invokes providers nor changes workflow
evidence. Eligibility remains false.

Independent Lead verification on Windows:

- All thirty isolated unit cases passed in 597.17 seconds, with no skips.
- Real Blender and Godot integration passed in 124.90 seconds, with no skips.
  Separate consumer copies were imported, explicitly launched and inspected for
  interactive controls, weighted mesh deformation, unchanged source Animation,
  root transforms, capsule and twelve bones. The original ten upstream files and
  all thirteen published files remained unchanged and current.
- The four applied files matched the reviewed isolated files. Four applied
  regression cases passed in 99.77 seconds: three/one authority gate counts,
  coherent source-and-review mutation during the gate, and corrupted staging
  rejected before publication.
- The applied-tree real Blender/Godot integration also passed, with no skips,
  in 125.89 seconds.
- Ruff check and format passed for all 270 Python files in `src` and `tests`;
  mypy passed for all 133 package source files.

Lead source review and independent reviewer found no remaining implementation
finding. This checkpoint does not claim completed final release CI, installed
release-wheel proof or Linux real-tool execution for the new review feature.
The actual deformation fixture is deliberately small, rather than a full art
asset. Camera framing uses cached initial-pose vertices and does not follow
arbitrary animated poses.

Currentness is a point-in-time check under the managed writer model. An external
change after publication can leave an immutable stale package; the exporter
fails and does not delete it. Adversarial mutate-and-restore sequences are not a
continuous monitoring guarantee. Consumers must import and run separate copies,
because Godot creates editor state inside a project directory.

The published v0.8.0-rc.2 remains immutable at main commit `4af8b769`. This
development checkpoint prepares v0.8.0-rc.3 and does not enable public production
rigged-character support.
