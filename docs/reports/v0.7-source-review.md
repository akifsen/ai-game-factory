# V0.7 standalone assembly source review

Current decision: **APPROVED for the standalone source slice**. After an
Antigravity network/tool interruption, a native implementation engineer completed
the revisions under the tooling-failure exception. The Team Lead independently
ran 190 source/domain and frozen legacy golden tests (all passed), the 19 retained
adversarial source probes (all passed), and five real Windows junction checks
(all rejected linked inputs). Ruff passed. Evidence is retained in
`.verification/source-root-no-replace.log`,
`.verification/source-revision-probes-final/report.json`, and
`.verification/source-junction-independent/report.json`. A separate independent
review approved the source slice. Interrupted tool executions are not passing
evidence.

The first revision passed 155 independently executed source and frozen legacy
golden tests (`.verification/source-revision-independent.log`). The default
pytest temporary directory was inaccessible; the successful run used an
explicit workspace temporary directory. Review still found reversed root
rotation multiplication, unchecked root translation, inadequate shear checks,
and incomplete package visibility before both files were published. A completion
marker and reader gate, with cleanup that preserves foreign files, were required.
Ingestion now enforces the same provenance sidecar size limit as verification.
These findings have been corrected and verified.

The first implementation's 37 domain/ingestion tests passed independently
(`.verification/source-independent.log`), but that did not establish the source
contract. Independent probes reproduced six failures in
`.verification/source-review-probes/report.json`:

- A GLB without mesh geometry was accepted.
- A GLB carrying skins was accepted.
- An accessor count outside the existing safety limit was accepted.
- Valid provenance metadata could be changed without a trusted pinned digest.
- A missing `paid` marker defaulted to false.
- A supposedly immutable result exposed a mutable provenance map.

Independent review also identified a POSIX empty-directory overwrite race in
publication and a link check performed after path resolution. Version and source
kind markers likewise defaulted when missing. The revision requires shared
bounded GLB geometry safety, authenticated provenance verification, exclusive
publication without replacing concurrent targets, lexical link checks, explicit
marker fields and detached immutable canonical authority.

Publication now exclusively claims a new directory and atomically hard-links
each source, provenance, and completion-marker file without replacement. Race
injections at all three destinations preserve foreign files. Unsupported
hard-link filesystems fail closed. The marker is the final package mutation;
subsequent staging-only cleanup is best-effort and cannot turn published success
into a reported failure. This does not claim whole-directory atomic visibility,
power-loss durability, or protection against a malicious actor modifying owned
files after publication. Readers require the completion marker and an external
pinned provenance digest before treating the package as verified.

The source and processed contracts must use one active identity `ROOT`, with the
logical root part directly beneath it. Source admission supplies only declared
LOD0 meshes and semantic nodes. Generated LOD1 and the rest-pose root box belong
to later processing. Canonical part/socket maps are checked against the bound
V0.7 specification; raw top-part transforms are interpreted only through the
explicit source-front normalization contract.

This is a standalone source foundation. Database, workflow, human source review,
Blender/Godot preservation, evidence bundles and advanced profile availability
are separate outstanding gates. No source is automatically approved and no
paid operation is created by this slice.
