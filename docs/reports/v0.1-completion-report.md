# AI GAME FACTORY — V0.1 COMPLETION REPORT

Yerel tarih: 2026-09-27. Başlangıç deposu boştu; Git deposu oluşturulmadı.
Bu rapor kaynakların §62/92/113 kapsamındaki Factory Core V0.1 içindir.

## Decision

**APPROVED WITH COMMENTS** — V0.1 davranışı bağımsız kod incelemesi, test, gerçek CLI kabulü ve temiz wheel kurulumu ile doğrulandı. Yorumlar: Linux fiziksel çalıştırması yapılmadı, üç Windows symlink testi atlandı; aşağıdaki sınırlamalar geçerlidir. Açık CRITICAL/MAJOR bulgu yok.

## Version

`0.1.0`; tek kaynak `src/gamefactory/__init__.py`, paket sürümü setuptools dynamic
metadata ile buradan alınır. Python 3.11+; yerel doğrulama Python 3.12.14/Windows.

## Architecture

`core/domain` yalnız Python alan modelleri, DAG ve durum makinelerini içerir.
CLI yapılandırma ve bağımlılıkları birleştirir. `workflows/engine.py` planlama,
politika, onay, claim/finalize ve bağımsız kanıt kontrolünü yönetir;
`workflows/builtin_tasks.py` sınırlı yerleşik görevleri uygular.
Sağlayıcı portu `workflows/ports.py`, eklenti sözleşmesi `workflows/handlers.py`.
SQLite repository'lerinin workflow façade içinde doğrudan birleştirilmesi V0.1
için bilinçli tercihtir; domain depolamadan bağımsızdır. Dört ADR karar ve
alternatifleri kaydeder. Genel DI framework veya tablo başına arayüz eklenmedi.

## Implemented

Kurulabilir CLI; katı proje sözleşmesi ve keşif; SQLite kayıtları; sıralı DAG;
politika/bütçe/onay; deneme geçmişi; resume/retry; artifact/hash/evidence/gate;
güvenli süreç yürütme; yetenek kaydı; gerçek Godot/Blender tespiti; açıkça
adlandırılmış yerel sahte sağlayıcıyla üç demonstrasyon iş akışı.
123 kaynak bölümü [izlenebilirlik tablosunda](../requirements/traceability.md)
izlenir; [gelecek sınırları](../requirements/future-boundaries.md) uygulanmış
özellik olarak sunulmaz. Dört kaynak kopyası orijinalleriyle içerik eşitliğiyle doğrulandı.

## CLI

`doctor`, `init`, `status`, `run demo|failure|paid-safety`, `resume`, `retry`,
`approvals`, `approve`, `reject`, `inspect`, `artifacts`, `--help`, `--version`.
`--project`, `--godot-path`, `--blender-path`, `--json` desteklenir.
JSON stdout tek değerdir; hatalar JSON stderr'dedir. Kodlar: 0 başarı,
1 config/kullanım, 2 workflow hatası, 3 blok/onay, 4 araç yok/hatalı, 5 iç hata.
CLI gizli etkileşim beklemez. Init var olan oyun dosyalarını değiştirmez.

## Persistence

`.gamefactory/state/factory.db`: projects, workflows, tasks, executions,
approvals, artifacts, evidences, quality_gates, audit_events, provider_invocations.
Dört sıralı migration, foreign keys, unique task/attempt ve SQLite transaction'ları.
Migration batch'i writer kilidiyle atomiktir; hata geri alınır, eşzamanlı kurulum
aynı migration'ı iki kez uygulamaz. Proje bütçesi claim sırasında seri olarak ayrılır.
Görev+deneme claim'i ve sonuç+görev+audit finalize işlemleri atomiktir.
Yeniden açılma ve başarısız deneme tarihçesi test edilir. Artifact dosyası ile DB
dağıtık transaction değildir: çökmede artık dosya kalabilir; belirsiz ücretli deneme
yeniden gönderilmez. Ağ paylaşımı/çok makineli DB destek iddiası yoktur.

## Workflow Engine

Linear, fan-out, fan-in, bağımsız dallar ve döngü reddi; başarısız önkoşulun
downstream görevleri çalışmaz. Onayda durma, ayrı süreçte resume ve açık retry
kalıcı kayıtlardan yürür. Tamamlanan görev yeniden çağrılmaz. Geçişler merkezi
durum makinelerinden geçer. Bilinmeyen görev ve geçersiz sonuç zarfı reddedilir.
Yerleşik görevler açık kayıtla ayrıdır; extension sonucu tek başına başarı sayılmaz.

## Policies & Approvals

Proje politikaları CLI bileşiminden gerçek motora aktarılır. Maliyetler sonlu ve
negatif olmayan değerlerdir; işlem/proje limitleri uygulanır. METERED/PAID/EXPENSIVE
sınıfları onay ve belirsiz sonuç korumasına dahildir. Görev sağlayıcının maliyet
sınıfını düşüremez. Onay fingerprint'i görev bağlamı, sağlayıcı, maliyet ve girdilere
bağlıdır; dispatch öncesi tekrar kontrol edilir. Karar aktörü, zaman, yorum ve
artifact referansları saklanır; compare-and-set aynı onayı iki kez kararlaştırmaz.
Ret veya değişiklik isteği sessiz yeni onay/çağrı başlatmaz.

## Artifacts & Evidence

Attempt'e özgü yönetilen çıktı yolları; exclusive text create; SHA-256, boyut,
producer, task/workflow ve validation metadata. Fiziksel dosya ve hash completion
öncesinde bağımsız doğrulanır. Eksik/değişmiş dosya başarıya dönüşmez. Kanıtlar
execution kimliğine bağlanır; gate kararı doğrulanan çıktılara dayanır.
`inspect` ve `artifacts` tarihsel metadata gösterir; bir tamamlanmış iş akışının
kaydı, sonradan elle değiştirilen dosyalar için sürekli bütünlük izleyicisi değildir.

## External Providers

Gerçek ücretli API çağrısı sayısı **0**. Meshy yalnız sınır ve PAID metadata'sıdır;
credential bulunsa bile transport uygulanmadığından `UNAVAILABLE` döner.
Demo/testte `FakeAssetGenerationProvider` açıkça enjekte edilir. Çağrı günlüğü

Günlük dış çağrıdan hemen önce kalıcı niyeti kaydeder: çağrıdan önce çökme olursa
gereğinden ihtiyatlı blok oluşabilir. Exactly-once garantisi iddia edilmez.

## Security

`shell=False`, argüman dizisi, explicit cwd, minimal child environment,
sınırlı stdout/stderr, timeout ve süreç ağacı temizliği. Windows batch dosyaları
örtük shell nedeniyle reddedilir. Bilinen secret değerleri ve hassas alanlar
hem sonuç zarfında hem SQLite payload yazım sınırında merkezi redaksiyondan geçer.
Gizli bilgi içeren görev parametreleri kayıttan önce reddedilir; fingerprint girdileri
sessizce değiştirilmez. Regresyon testi ham SQL satırları ve DB/WAL baytlarını denetler. Traversal, UNC, ADS/device, symlink/junction kaçışları
kontrol edilir. Workflow kimliği lock yoluna doğrudan katılmaz; OS lock ve
bağlantı/hardlink denetimi kullanılır. Config/state kökü ilk yazmadan önce doğrulanır.
Bu araç kötü niyetli yerel Python plugin'lerini veya aynı kullanıcı hesabının
dosya sistemine doğrudan müdahalesini izole eden işletim sistemi sandbox'ı değildir.

## Recovery

OS kilidi canlı workflow sahibini korur; süreç ölünce kilit serbest kalır.
Çökmüş ücretli/ölçümlü yürütme UNCERTAIN/BLOCKED kalır; retry/resume yeni dış istek
göndermez. Uzlaştırma insan/gelecek sağlayıcı query desteği gerektirir; V0.1 otomatik
reconciliation komutu yoktur. Yerel transient retry yeni attempt ekler; geçmişi silmez.

Sahte ücretli senaryoda onaysız **0**, onaylı **1**, yeni süreçte tekrar resume
sonrasında **1** çağrı. Reddedilen onayda **0**. Crash-after-acceptance,
değişen girdiler, maliyet düşürme ve bütçe yarışları ayrı regresyonlarla denetlenir.
Bu gerçek sağlayıcı faturalaması/idempotency desteği doğrulaması değildir.

## Known Limitations

- Linux/Python 3.11 fiziksel çalıştırması: **NOT AVAILABLE IN TEST ENVIRONMENT**.
  Windows/Linux ve 3.11/3.12 CI matrisi hazır; uzak CI çalıştırılmadı.
- Üç symlink testi Windows yetkileri nedeniyle atlandı; junction yolları ayrıca çalıştırıldı.
- Gerçek Meshy, AI/vision/audio, Blender işleme, Godot harness, web UI ve dağıtık
  yürütme kapsam dışı; ayrıntılı sözleşmeleri gelecek sınırları belgesinde.
- Yerel onay aktörü audit bilgisidir; çok kullanıcılı kimlik doğrulama sistemi değildir.
- Windows Job Object ataması kullanılamazsa süreç ağacı temizliği taskkill'a dayanır.
- Read-only DB tanı testi kontrollü hata enjeksiyonudur; Windows ACL sertifikasyonu değildir.
- Python handler'lar aynı süreçte çalışır; kötü niyetli/hung plugin için ayrı worker
  izolasyonu yoktur. Timeout/süreç ağacı garantisi ProcessRunner görevleri içindir.

## Major Findings

## Minor Findings

Yerleşik görev adlarının reserved-name listesi ve action registry'de iki yerde
tutulması küçük bakım borcudur; yeni görev eklerken ikisi birlikte güncellenmelidir.
Linux CI sonuçlarının bulunmaması ve Windows symlink testlerinin atlanması,
destek iddiasının sınırlarıdır. V0.1 dış üretim entegrasyonları eksik özellik gibi
gizlenmez. Uzak yayın/release yapılmadı.

## Architecture Drift

İlk uygulamadaki fake'e özel motor bağımlılığı ve büyük görev switch'i ayrıştırıldı;
sağlayıcı kontratı iç katmana alındı. Somut SQLite bileşimi bilinçli ADR istisnasıdır.
Framework, servis broker'ı, çoklu ajan platformu veya uzak plugin yükleme eklenmedi.

## 6-Month Maintainability

Tek Python paket, CLI, dört migration ve küçük deterministik görev kayıtlarıyla
çekirdek yönetilebilir. Yeni görev için handler+kanıt ve hata senaryosu gerekir;
engine'e vendor dalı eklenmemelidir. Sonraki değişiklikler aynı kabul betiğini çalıştırmalıdır.

## 1-Year Maintainability

Gerçek sağlayıcı gelince dış operation query/reconciliation ve maliyet birimleri
açık sözleşmeye dönüşmelidir. Birden fazla gerçek storage ihtiyacı ortaya çıkarsa
atomik uygulama işlemleri etrafında dar unit-of-work portu değerlendirilir;
şimdiden tablo başına arayüz üretmek gerekmez.

## 3-Year Maintainability

Çok makine, çok kullanıcı veya uzun yaşayan işler mevcut local-first varsayımlarını
değiştirir; bu kullanım için yeniden mimari karar ve migration/operasyon testleri
gerekir. Bugünkü OS workflow kilidi dağıtık lease olarak sunulmaz. Bu teslim,
üç yıllık ölçek iddiası yerine genişletilebilir ve sınırları belirli bir temel sağlar.

## Simplicity

argparse, sqlite3 ve pathlib; yalnız config için Pydantic/PyYAML. Sıralı scheduler,
yerel dosyalar, tek sağlayıcı portu ve açık task registry. Kullanılmayan fake sınıflar,
uzak marketplace ve soyut event bus eklenmedi.

## Pattern Consistency

Alan enum/dataclass'ları, merkezi geçiş/politika, repository dönüşümleri, açık
adaptörler ve JSON hata zarfı tutarlı. Test ve demo sahteleri isimle belirtilir;
production detection bunlarla değiştirilmez. Attempt geçmişi güncel sonuçtan ayrı tutulur.

## Long-Term Verdict

V0.1 yerel deterministik orkestrasyon temeli olarak değerlendirilir. Üretim asset
fabrikası veya otonom oyun üreticisi olarak sunulmaz. Son karar bağımsız test,
inceleme, gerçek CLI ve paket kurulumunun birlikte doğrulanmasına bağlıdır.
