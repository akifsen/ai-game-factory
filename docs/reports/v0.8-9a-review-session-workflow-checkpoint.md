# V0.8-9a live review session workflow checkpoint

The workflow binds durable annotations to the exact ordered V0.8-8 review set and its public live currentness authority. It uses `AnimationReviewSessionWorkflowContext` with existing handlers, workflow ID, preview directory, ordered clip sources, review directory, and an optional explicit session path. Public operations create a session, apply one operation with an expected raw SHA-256, and query session currentness.

Each authority capture reads the bounded manifest and ordered clip bytes before and after the public `animation_review_set_current` gate and requires an unchanged binding. The domain's global clip payload digest maps to the manifest's `nested_clips_payload_digest`; each clip separately binds its raw clip digest and duration. Creation and updates repeat this capture in the store's final locked precommit callback. Coherent gate-time swaps and foreign bindings cannot authorize a write.

Results distinguish a durable commit from subsequent currency. A successful write returns `committed=True` and the committed session with its raw SHA. If upstream evidence changes, becomes malformed, or cannot be read after publication, the result returns `current=False` and retains the durable historical record. There is no shared transaction or rollback with upstream database/export writers. Historical store reads remain available when currency fails; new mutations are rejected before commit.
