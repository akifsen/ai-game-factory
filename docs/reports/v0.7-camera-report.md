# V0.7 review camera verification

Decision: **APPROVED for local engineering quality**.

The camera slice implements every ADR 0014 review placement in Python and the
packaged Godot harness: front, rear, left, right, side, three_quarter,
three_quarter_front, three_quarter_rear and top. Unknown views fail explicitly.
The historical `side` scale-reference and correction rules remain specific to
`side`; `right` shares its placement without inheriting those special rules.

Independent verification on September 30, 2026:

- Camera, profile, cold verifier and authoritative compatibility tests:
  **154 passed** (`.verification/camera-independent.log`).
- Real Godot 4.7.2 rendered all nine views of the retained local pickup fixture.
  Each decoded PNG is 1280×720. All framing observations report the expected
  Python axis label, viewport containment and margin acceptance.
- An unknown view request exited unsuccessfully with the explicit unknown-angle
  error before importing the asset or writing observations/captures. No fallback
  PNG was generated.
- Runtime report: `.verification/v07-views-runtime-final/report.json`; captures,
  observation JSON and engine logs remain beside it. Paid calls: **zero**.
- An initial verification script expected an observation for an invalid request;
  that assumption was corrected to match intentional rejection before loading.
  Its logs remain in `.verification/v07-views-runtime/`.
- Independent code review found no actionable camera defects. A subsequent
  independent parity run exposed an environment-variable mismatch in the new
  test: it skipped rather than running with the established CI Godot variable.
  The revision aligns it with `GAMEFACTORY_TEST_GODOT`; skipped tests are not
  counted as executed runtime checks. The final independent combined run used
  that variable and passed **169 tests with no skips**, including three real
  Godot probes, request guards and 105 unchanged compatibility goldens
  (`.verification/camera-final-independent.log`).
- Explicit empty, unknown, duplicate and non-string capture views fail before
  staging; non-string cold-verifier views produce a controlled validation error.
- Independent targeted Ruff lint/format passed (nine files); mypy passed for
  four production/verifier modules.

This verifies a camera implementation slice, not V0.7 product readiness. The
advanced profile source, processing, runtime and evidence paths remain pending.
Remote CI must be reported for the exact checkpoint SHA after authorized push.
