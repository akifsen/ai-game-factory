# V0.8-11a review triage implementation checkpoint

The Godot session panel now derives reviewed/total and unreviewed/revise/keep counts, filters clips by the four exact status options, and navigates previous/next revise clips in caller order. Filtering leaves playback selection unchanged; a separate selector uses the existing Playback selection API. Historical stored sessions retain derived navigation while mutation controls keep their existing authority rules. Without a saved session, counts are explicitly provisional; inventory mismatch disables triage.

The existing validation probe now covers count totals, three-way status projection, terminal keep projection, caller order, mixed-status nearest navigation, wrap, invalid filters, mismatch and zero/sole-current revise no-ops. The filtered selector clips long IDs inside the existing scroll panel. No schema, persistence, backend, CLI or CI job is added.

The engineer revised those findings. Independent Godot 4.7.2 checks passed controller and inspector syntax plus the existing bridge/triage probe, both before and after application. The minimal probe exercises helpers without a live exported scene; it does not prove the full UI lifecycle.
