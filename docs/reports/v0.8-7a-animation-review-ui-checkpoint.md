# V0.8-7a animation review UI checkpoint

This development slice adds a Godot review scene and controller for a current
V0.8-6 authored animation package. It provides Play, Pause, Restart, a continuous
timeline, elapsed time/duration, session loop and exactly 0.25x, 0.5x, 1x and 2x
playback speeds. Invalid speeds fail without changing the player state.

The controller deep-clones the source Animation for review. Loop overrides affect
that clone; authored JSON, source tracks and duration remain unchanged. Camera,
lighting and controls are siblings of the verified character. Camera framing
uses cached world vertices from the initial pose and adjusts to the viewport and
panel bounds. Resizing preserves a paused seek position and active playback.
Framing does not follow arbitrary animated poses.

Independent Lead verification on Windows with Godot 4.7.2:

- Three integration checks passed in 14.52 seconds with zero skips, covering
  script parsing, standalone scene launch, controls and the full inspector.
- A separate rendered consumer passed controls, weighted mesh deformation,
  unchanged source tracks, transforms, capsule and bones. It projected the mesh
  above the controls at 1152x648, 1280x720 and 960x640, and checked resizing during
  paused and active playback. The rendered frame was visually inspected.
- All ten original V0.8-6 package files retained their original SHA-256 values.
- Applied source files matched the reviewed isolated implementation. Ruff check
  and format passed for the new Python integration test.

Lead and independent reviewer approved this UI slice. The Python review exporter
and currentness API are a separate next slice; this checkpoint does not claim a
published review package, Linux real-tool proof or completed release CI. The
optional UI tests require an explicitly supplied current animation package.

The published v0.8.0-rc.2 remains immutable at main commit `4af8b769`; it does not
include this UI or V0.8-6 authored clip ingest. Production and promotion
eligibility remain false, and public rigged character support remains unavailable.
