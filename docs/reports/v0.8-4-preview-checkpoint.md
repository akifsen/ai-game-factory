# V0.8-4: readiness-gated Godot character preview

The development checkout adds `export_rigged_character_candidate_preview()` and
`candidate_preview_current()`. Export requires engine-finalized, current C2-B
evidence, copies the verified processed GLB unchanged, and publishes a fresh
Godot package without overwrite. The package contains a character scene, capsule,
versioned candidate/specification envelope and deterministic manifest.

Currentness regenerates expected bytes and hashes from live evidence bindings.
Rehashing a modified scene cannot make it current. Manifest reads are bounded,
duplicate keys are rejected, and JSON controls are compared with exact types.
Source, specification, profile, revision and receipt drift invalidate previews.
Staging is beside the output, with lexical link checks and guarded cleanup.
Production and promotion eligibility remain false.
