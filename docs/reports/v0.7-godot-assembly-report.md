# V0.7 Godot Assembly Runtime Verification

## Result

The standalone verifier accepts only exact typed V0.7 assembly specifications and profiles, requires the specification-bound profile to equal the supplied profile, and limits the processed GLB to 50 MiB. It hashes and bounded-parses the input before staging, derives PART/socket/collider facts from those exact bytes, stages a fresh attempt directory, and re-reads the staged GLB immediately before engine dispatch.

Runtime reports bind workflow, revision, execution, attempt, asset, processed-file hash, request digest, exact harness SHA-256, canonical full-profile SHA-256, and canonical full-specification SHA-256 for both PASS and FAIL. The result artifacts retain the request, observation, and exact packaged harness bytes. Source PART/socket position and orientation are checked against the bound profile's positional and geodesic angular tolerances, matching source geometry validation; quaternion sign changes represent the same rotation. Godot observations are still compared to exact processed-GLB facts at strict precision. Python independently compares imported PART local position/basis/scale and motion extras, LOD inventory, socket local and full-ancestor world matrices (including accepted positive uniform ancestor scale), and COL bounds against the processed GLB. Godot performs actual import, runtime motion, restoration, physics, framing, and capture checks. Only the requested profile views are accepted; invalid view names are rejected before staging.

The verifier preserves the geometry contract's positive uniform PART scale. It rejects reflected and sheared PART bases. Runtime findings remain separate from source authorship authentication and human review.

## Verification

The focused unit and integration tests were run against Godot 4.7.2 on Windows using:

```powershell
$env:GAMEFACTORY_TEST_GODOT='C:\Users\lenovo\devel\godot\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe'
.venv\Scripts\python.exe -m pytest tests/unit/test_godot_assembly.py tests/integration/test_godot_assembly_real.py -q --basetemp .verification/godot-native-final-tests
```

The final run reported **48 passed** (including real Godot import/runtime tests). The rotated tank positive case uses a turret at uniform scale 2 with small in-tolerance pivot/socket position and angular deviations, runs bounded motion, proves exact restoration, validates its muzzle socket through the scaled ancestor, and renders and decodes all nine profile views. The prismatic articulation and missing-capture rejection also exercise the real engine. Processed-file negatives cover incorrect parentage, an unexpected semantic ROOT wrapper, pivot basis, motion axis, socket transform, missing collider, reflection, and shear. Unit cases cover profile tolerance boundaries and quaternion-sign equivalence, typed/profile binding, the prelaunch 50 MiB limit, strict FAIL-report revision/hash/profile/attempt identity, malformed observation payloads, tampered transform observations, stale request digest, fresh output paths, and invalid view identifiers.

Quality checks:

- Ruff check and format check for the adapter and the two focused test modules: passed.
- Mypy for `godot_assembly.py`: passed.
- Pytest emitted a cache warning because the environment denies writes to repository `.pytest_cache`; tests used the explicit `.verification` basetemp.
