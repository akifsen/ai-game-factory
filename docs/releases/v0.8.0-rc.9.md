# v0.8.0-rc.9 — Master Factory workflows

This candidate adds reusable development workflows for independent Godot games:

- Strict, versioned design/feature/level/UI/image/audio/vision manifests with
  dependency graphs, bounded agent context, provider contracts and human gates.
- Codex proposals, OpenAI image/speech/vision adapters and fixed operator process
  providers, with durable intent, cost accounting and conservative recovery.
- Deterministic code, gameplay and performance evidence, advisory visual review,
  candidate promotion and exact approval/artifact binding.
- Project creation/discovery/onboarding, accepted asset installation, native Godot
  operations, export evidence and hash-bound release manifests.
- Versioned packaged prompts, the Godot harness, CLI commands and usage examples.

The release also includes the earlier Tide Bastion Codex planning and validated
static-prop reuse work from the product pilot branch.

Local validation: 2,081 distinct tests passed and 41 were skipped. Mypy, Ruff,
real Godot/Blender checks and offline wheel installation passed. Initial local
regression errors were resolved with short writable paths, isolated Godot user
directories, certificate-store access and a fresh fixture. The 428 slow installed
candidate CI cases were not executed locally; the existing full CI gate remains
required. See [the verification report](../work-plan-master-completion.md).

Publication qualification is pending the relevant remote checks and exact-main
full CI. This document is a candidate changelog, not evidence of a published
release. Paid live providers remain operationally unverified. Speech does not
claim music/SFX support; rigged-character production remains experimental.
