# V0.8-12a animation compare runtime (checkpoint)

Disposable Godot overlay for synchronized side-by-side comparison of two clips from one **current** V0.8-8 animation review set.

## Python API (supported entry points)

This slice exposes **prepare/run helpers only**. There is no supported `python -m` or console-script CLI for compare launch.

```python
from gamefactory.cli.animation_review_compare_viewer import (
    prepare_animation_review_compare_viewer,
    run_animation_review_compare_viewer,
)

prepared = prepare_animation_review_compare_viewer(
    handlers,
    workflow_id,
    preview_dir,
    clip_packages,
    review_dir,
    overlay_dir,
    left_clip_id,
    right_clip_id,
)
argv = prepared.godot_argv(godot_executable=godot_path)
```

`prepare_animation_review_compare_viewer` gates `animation_review_set_current` before capture and again after overlay materialization plus compare resource install, re-checking canonical review-set bytes against the initial snapshot. Clip selectors are validated against the captured manifest (not a pre-capture read). `run_animation_review_compare_viewer` re-gates currentness immediately before launching Godot, owns a temporary overlay directory, and cleans it up after Godot exits.

## Godot scene

`animation_review_compare.tscn` renders two independent `SubViewport` panes with the trusted review-set preview player, shared normalized timeline transport, and per-pane canonical rest-bounds camera fit. Each pane fits using that `SubViewport`'s visible rectangle and canonical edge margins (split layout excludes the bottom control panel from the 3D viewports).

## Camera fit assumption

The bottom transport panel lives outside the `SubViewport` split (`ViewportSplit` is offset above the panel). Safe projection rectangles are derived per pane from `SubViewport.get_visible_rect()` with fixed edge margins; no cross-coordinate mapping from the main window control panel.

This guide covers the fast runtime checkpoint only; rendered deformation acceptance and release closure are separate slices.
