# Animation review session handoff

The development handoff API exports saved animation review annotations as `review-report.json` and `review-report.md`. It reads a durable V0.8-9 session and preserves its clip order, status, note and bookmarks. Keep remains an annotation; production and promotion eligibility are always false.

Use the same `AnimationReviewSessionWorkflowContext` that identifies the existing session and its original source packages. The caller supplies the existing candidate handlers and workflow ID. Choose a fresh absolute output directory separate from the review set, character preview, animation packages, authored clip files and session sidecar directory.

```python
from pathlib import Path

from gamefactory.workflows.animation_review_handoff import export_animation_review_handoff

# ctx is the existing AnimationReviewSessionWorkflowContext.
report = export_animation_review_handoff(ctx, Path("C:/gamefactory/handoff/review-01"))
print(report.review_report_markdown)
print(report.review_report_json)
```

Both files include the captured session revision, raw session SHA, review-set digests and `session_current`. JSON preserves annotation text exactly. Markdown displays untrusted text literally, normalizes display line endings to LF, and starts with a historical warning when the saved session is no longer current. Each file is limited to 128 KiB.

A valid stale session can still be exported to describe historical annotations. Restore sources and recheck the original workflow before interpreting currentness. Malformed or oversized sessions fail validation. The exporter never writes annotations or modifies source packages.

Two exports of the same session and currentness state produce identical report bytes. Export refuses an existing destination, including an empty directory. A concurrent session change fails rather than publishing a report for a different revision. Reports use a fresh owned stage and atomic publication on supported Linux and Windows filesystems; currentness is a point-in-time observation, not a global transaction with source or database writers.

The public-gate and actual Blender/Godot handoff acceptance passed against source and an independently installed RC5 wheel. See the [technical closure report](../reports/v0.8-10-review-handoff-technical-closure.md). Release qualification still requires the normal main CI and final CI-built-wheel audit.
