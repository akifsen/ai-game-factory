# V0.8-4 candidate character Godot preview

Readiness-gated export turns engine-finalized C2-B evidence into a **standalone**
Godot preview directory. The preview is **test-only**: every control document sets
`production_eligible=false` and `promotion_eligible=false`.

## API

- `export_rigged_character_candidate_preview(handlers, workflow_id, output_dir)`
  requires `assert_candidate_workflow_engine_finalized` / live evidence readiness,
  copies the registered **processed GLB bytes** (hash-verified), and publishes a
  fresh directory atomically (no overwrite).
- `candidate_preview_current(handlers, workflow_id, preview_dir)` resolves a single
  live `_PreviewBindings` snapshot and requires the on-disk package to match the
  deterministic manifest and canonical file bytes implied by that snapshot (not
  merely self-consistent `file_digests`). Stale or not-ready evidence returns
  `False`; tampered or invalid layouts raise typed validation/currentness errors.

Callers must pass explicit `CandidateWorkflowHandlers`; the preview layer performs
no database writes, provider calls, or Blender/Godot work during export.

Use the handlers from the completed managed candidate workflow:

```python
from gamefactory.workflows.v08_candidate_preview import (
    candidate_preview_current,
    export_rigged_character_candidate_preview,
)

preview = export_rigged_character_candidate_preview(handlers, workflow_id, "preview-out")
assert candidate_preview_current(handlers, workflow_id, preview.preview_root)
```

The destination must be fresh. Staging lives beside the destination so the source
workspace may be on another volume. The currentness check is a live query: a later
change to candidate evidence makes an existing preview stale.

## Package layout

Exactly these files (no extras):

| File | Role |
|------|------|
| `character.glb` | Verified processed GLB from identity task binding |
| `character.tscn` | `Node3D` root, instanced GLB, `StaticBody3D` + capsule collider |
| `candidate.json` | Versioned preview envelope containing the unchanged specification and ineligible flags |
| `collider.json` | Capsule radius/height and GLB-derived `center_m` |
| `preview-manifest.json` | Deterministic binding to workflow + C2 triplet + file SHA-256 |
| `project.godot` | Minimal compatibility renderer settings (`run/main_scene` → `character.tscn`) |

`preview-manifest.json` is not readiness authority; live readiness wins on
`candidate_preview_current`.

Keep this canonical package intact. Copy it into a separate Godot consumer project
before importing or inspecting it; Godot creates import/cache files. The acceptance
test consumes such a copy and then checks the canonical package is still current.
