# V0.8-5 candidate character animation preview

Readiness-gated export builds a **standalone** Godot animation preview directory from
engine-finalized C2-B evidence and an explicit, **current** V0.8-4 character preview
package. The animation preview is **test-only**: control documents set
`production_eligible=false` and `promotion_eligible=false`.

## API

- `export_rigged_character_animation_preview(handlers, workflow_id, preview_dir, output_dir)`
  requires live evidence readiness, a caller-supplied V0.8-4 preview directory that
  passes `candidate_preview_current`, copies upstream canonical bytes unchanged, and
  publishes a fresh animation package atomically (no overwrite).
- `animation_preview_current(handlers, workflow_id, preview_dir, animation_dir)` resolves
  live evidence bindings, requires the upstream preview to remain current, and checks
  that the animation package matches deterministic manifest and file bytes implied by
  that snapshot (not caller-rehashed tampering). Stale evidence or upstream preview
  returns `False`; invalid layouts raise typed validation/currentness errors.

The export layer performs no database writes, provider calls, or Blender/Godot work.

```python
from gamefactory.workflows.v08_candidate_preview import export_rigged_character_candidate_preview
from gamefactory.workflows.v08_candidate_animation_preview import (
    animation_preview_current,
    export_rigged_character_animation_preview,
)

preview = export_rigged_character_candidate_preview(handlers, workflow_id, "preview-out")
animation = export_rigged_character_animation_preview(
    handlers, workflow_id, preview.preview_root, "animation-out"
)
assert animation_preview_current(handlers, workflow_id, preview.preview_root, animation.animation_preview_root)
```

## Package layout

Exactly these files (no extras):

| File | Role |
|------|------|
| `character.glb` | Unchanged bytes from upstream V0.8-4 preview |
| `character.tscn` | Unchanged bytes from upstream V0.8-4 preview |
| `candidate.json` | Unchanged upstream preview envelope |
| `collider.json` | Unchanged upstream collider metadata |
| `preview-manifest.json` | Unchanged upstream preview manifest (hash bound in animation manifest) |
| `animation_preview.tscn` | Instanced `character.glb` + `AnimationPlayer` with runtime clip builder |
| `animation_preview_player.gd` | Builds `rig_smoke_01` rotation track on `LeftUpperArm` |
| `animation_spec.json` | Frozen clip contract (1s loop, Y 20° peak at t=0.5) |
| `animation_manifest.json` | Deterministic binding to workflow, C2 triplet, upstream manifest hash, file digests |
| `project.godot` | Minimal compatibility renderer (`run/main_scene` → `animation_preview.tscn`) |

`animation_manifest.json` is not readiness authority; live readiness and upstream
preview currentness win on `animation_preview_current`.

Copy the package into a separate Godot consumer project before import or inspection.
Godot creates import/cache files. Integration tests consume such a copy.

## Tests

- Unit: `tests/unit/test_v08_candidate_animation_preview.py` (completed C2-B managed fixture).
- Integration: `tests/integration/test_v08_candidate_animation_preview_real_tools.py`
  (real Blender + Godot when `GAMEFACTORY_TEST_BLENDER` / `GAMEFACTORY_TEST_GODOT` are set).

The exported scene starts `rig_smoke_01` automatically. Its runtime loader accepts
only the closed clip specification; changing a bone, key, duration, threshold or
eligibility value prevents the clip from being registered.

Rendered animation inspection harness (not shipped in the package):
`src/gamefactory/resources/v08_candidate/animation_preview_inspect.gd`.

Import may run headless, but deformation inspection requires the real compatibility
renderer and `--audio-driver Dummy`. On Linux run it under an available display
(for example Xvfb). The headless dummy renderer cannot establish a valid skin bake.
The inspector pauses the automatically playing clip before exact seeks at 0 and
0.5 seconds, checks the actual skeleton track and pose, then compares affected and
unaffected baked vertex regions while the capsule and root transforms remain fixed.
