# V0.8-7 rigged character animation review

Readiness-gated export builds a **standalone** Godot animation review directory from
engine-finalized C2-B evidence, an explicit **current** V0.8-4 character preview,
a bounded local animation clip, and a **current** V0.8-6 animation clip preview package.
The review package is **test-only**: manifests set `production_eligible=false` and
`promotion_eligible=false`.

## API

- `export_rigged_character_animation_review(handlers, workflow_id, preview_dir, clip_path, animation_dir, output_dir)`
  gates on **three** `animation_clip_preview_current(...)` checks (pre-stage, pre-publish,
  post-publish), copies the bounded **10** V0.8-6 package bytes unchanged, adds trusted review
  UI, inspects the staged **13**-file tree against expected **12** digests and the canonical
  review manifest **immediately before** atomic publish, then publishes (no overwrite).
- `animation_review_current(handlers, workflow_id, preview_dir, clip_path, animation_dir, review_dir)`
  snapshots the exact **10** V0.8-6 package files, calls `animation_clip_preview_current` **once**
  (the only public upstream gate), re-snapshots those **10** files and returns `False` when the
  before/after byte maps differ (point-in-time TOCTOU guard), then inspects the review tree against
  the **before** snapshot. Stale upstreams return `False`; incoherent file digests raise
  `CandidateCurrentnessError`; invalid layouts raise typed `ValidationError`.

The export layer performs no database writes, provider calls, or Blender/Godot work.

```python
from gamefactory.workflows.v08_candidate_preview import export_rigged_character_candidate_preview
from gamefactory.workflows.v08_candidate_animation_clip_preview import (
    animation_clip_preview_current,
    export_rigged_character_animation_clip_preview,
)
from gamefactory.workflows.v08_candidate_animation_review import (
    animation_review_current,
    export_rigged_character_animation_review,
)

preview = export_rigged_character_candidate_preview(handlers, workflow_id, "preview-out")
clip_preview = export_rigged_character_animation_clip_preview(
    handlers, workflow_id, preview.preview_root, "clips/arm_wave_01.json", "clip-preview-out"
)
review = export_rigged_character_animation_review(
    handlers,
    workflow_id,
    preview.preview_root,
    "clips/arm_wave_01.json",
    clip_preview.animation_clip_preview_root,
    "review-out",
)
assert animation_review_current(
    handlers,
    workflow_id,
    preview.preview_root,
    "clips/arm_wave_01.json",
    clip_preview.animation_clip_preview_root,
    review.animation_review_root,
)
```

## Package layout

Exactly **13** regular files (no extras, no nested directories):

| File | Role |
|------|------|
| *(10 V0.8-6 files)* | Byte-identical to the authoritative `animation_dir` package |
| `animation_review.tscn` | Trusted review scene (`res://animation_clip_preview.tscn` instance + UI) |
| `animation_review_controller.gd` | Trusted interactive review controller |
| `animation_review_manifest.json` | Deterministic binding manifest (`candidate-character-animation-review-manifest-0.8.0`) |

`project.godot` is copied **unchanged** from the V0.8-6 package (`run/main_scene` remains
`res://animation_clip_preview.tscn`). Launch review explicitly:

```text
godot --path <review-root> --scene res://animation_review.tscn
```

`animation_review_inspect.gd` is a packaged trusted tool for consumer copies only; it is **not**
part of the published 13-file tree.

## Manifest contract

`animation_review_manifest.json` uses a **compact** closed key set (no absolute paths,
timestamps, randoms, or duplicated C2 triplet fields — those remain on the copied
`animation_clip_manifest.json`). Keys: `schema_version`, `workflow_id`,
`upstream_animation_manifest_sha256` (raw SHA-256 of copied `animation_clip_manifest.json`),
`upstream_animation_package_sha256` (canonical digest of all **10** V0.8-6 file digests),
`clip_sha256`, `file_digests` for all **12** non-manifest files (10 V0.8-6 originals plus two
review UI resources), `animation_review_status`, and explicit `false` eligibility flags.

Export **result** objects still surface C2 identity fields by reading the validated upstream
`animation_clip_manifest.json` (snapshot fingerprint, artifact IDs, GLB hash, preview manifest
hash, etc.).

Trusted UI digests are defined by checked-in resources (LF-normalized), not caller-supplied
hashes.

## Currentness and drift

- Pre-stage, pre-publish, and post-publish barriers re-check `animation_clip_preview_current`;
  pre-publish also requires the bounded **10**-file byte snapshot to be unchanged.
- Pre-publish **stage inspection** rejects corrupt or mis-bound staged output with **no**
  published directory (fail-closed before `atomic_publish_staged_container`).
- If live authority drifts **after** a successful publish, `animation_review_current` returns
  `False` for the immutable published directory; exporters do not delete published output.

Bounded reads follow existing V0.8-6 limits (64 MiB GLB, 64 KiB clip JSON, 128 MiB package total).

## Godot consumer behavior

Copy the published package into **separate consumer directories** before import, scene launch,
or SceneTree inspection. Never run `--import` or harness scripts against the immutable published
13-file tree: import creates `.godot` editor state and can make `animation_review_current`
appear stale even when upstream authority is unchanged.

| Consumer copy | `project.godot` | Purpose |
|---------------|-----------------|---------|
| Launch | **Unchanged** (keep `run/main_scene`) | Headless `--import`, then explicit `--scene res://animation_review.tscn` |
| Inspect | Strip `run/main_scene` only | Append `animation_review_inspect.gd`, import, run full interactive inspect |

The published export directory must remain byte-identical after Godot checks: exactly **13**
names, all **10** V0.8-6 bytes and all **13** review bytes unchanged, with
`animation_review_current` still `True` against the live animation clip preview package.

For SceneTree harness tests, run the inspect script **without**
`--gf-controller-numerics-only` so baked arm-wave deformation is validated. Expect
`PASS: animation_review_interactive` (numerics-only is a cheaper check-only path and does not
substitute for interactive deformation in integration). Treat Godot stdout/stderr as failure on
`SCRIPT ERROR`, `ParseError`, or `ERROR:` lines even when the process exits 0.

## Export stability (point-in-time)

Export captures a **point-in-time** V0.8-6 byte snapshot at pre-stage, pre-publish, and
post-publish gates. The pre-publish stage barrier compares the staged **13**-file tree to live
authority **immediately before** atomic publish; corrupt staging never publishes.

After publish, the directory is **immutable** from the exporter’s perspective: if live
`animation_dir` drifts, `animation_review_current` returns `False` without deleting output.
Coherent in-package V0.8-6 rehash (manifest + digests updated together) on a **copy** of the
review tree while live `animation_dir` stays at state **A** yields the same `False` currentness
even though `animation_clip_preview_current` on the real upstream remains `True`.

Tests assume **A → B** drift scenarios only (live upstream unchanged vs review snapshot drift, or
live upstream drift vs frozen review). **ABA** round-trips (mutate away and restore identical
bytes) are excluded from currentness oracles.
