# V0.8-9 animation review sessions

A session stores working notes for an existing two-to-eight-clip review set. Each clip has an `unreviewed`, `keep`, or `revise` status, a note of at most 2 KiB of UTF-8, and up to 32 unique bookmarks within its duration. Keep is a reviewer annotation; production and promotion eligibility remain false.

First export the character preview, authored clip previews, and immutable review set through the [multi-clip review workflow](v0.8-8-multi-clip-animation-review.md). Preserve the candidate workspace and its existing `.gamefactory/state/candidate-factory.db`. The viewer checks live currentness through that database and the original source packages when editing annotations.

Save this context outside the exported packages. Replace the example paths and workflow ID with the existing inputs, retain the original clip order, and use absolute paths. Create the separate exchange and session parent directories. `session_path` may be `null` to use the default separate sibling session location.

```json
{
  "schema_version": "animation-review-session-context-0.8.0",
  "project_root": "C:/gamefactory/candidate-workspace",
  "workflow_id": "YOUR_EXISTING_WORKFLOW_ID",
  "preview_dir": "C:/gamefactory/character-preview",
  "review_dir": "C:/gamefactory/review-set-out",
  "clip_packages": [
    {
      "animation_dir": "C:/gamefactory/wave-preview",
      "clip_path": "C:/gamefactory/clips/wave.json"
    },
    {
      "animation_dir": "C:/gamefactory/idle-preview",
      "clip_path": "C:/gamefactory/clips/idle.json"
    }
  ],
  "session_path": "C:/gamefactory/review-notes/session.json",
  "exchange_dir": "C:/gamefactory/session-exchange"
}
```

Start the viewer from the Python environment containing Game Factory:

```powershell
python -m gamefactory.cli.animation_review_session_viewer --context-file C:/gamefactory/session-context.json --godot-executable C:/tools/godot/Godot.exe
```

The launcher opens a temporary copy with the packaged session interface and removes that copy when Godot exits. It leaves the canonical review package and original authored clips unchanged. Saved notes remain in the separate session file. Godot and the Python environment must be available locally.

Create the session when the current review set is ready, select a clip, choose its status, and save its note. Scrub playback and add a bookmark to preserve that position; selecting a saved bookmark seeks playback without changing the authored clip. Changing clips pauses and resets playback while retaining saved annotations for each clip.

If another viewer saves first, an old raw SHA cannot overwrite its changes. The interface reports conflict and requires Reload before another save. An unsaved note remains a draft; check it after reloading before saving again. A missing command response also requires Reload because the command may already have committed.

When the candidate database is unavailable or original inputs become stale, a valid saved session stays readable and editing is disabled. Restore the original sources and database, then reload to recheck currentness. Malformed session files fail closed. A structurally invalid or modified executable review package cannot be opened by this viewer. Session persistence coordinates writers using this store; arbitrary external file replacement is outside its transaction guarantee.
