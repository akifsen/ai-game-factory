# V0.8-6 authored local animation clip preview

Readiness-gated export builds a **standalone** Godot animation clip preview directory from
engine-finalized C2-B evidence, an explicit **current** V0.8-4 character preview package,
and a caller-supplied local `rig-animation-clip-0.8.0` JSON file. The clip preview is
**test-only**: control documents set `production_eligible=false` and
`promotion_eligible=false`.

## API

- `export_rigged_character_animation_clip_preview(handlers, workflow_id, preview_dir, clip_path, output_dir)`
  requires live evidence readiness, a current V0.8-4 preview directory, and a bounded local
  animation clip that passes skin-influence checks against the preview GLB. It copies upstream
  canonical bytes unchanged, embeds the **original raw clip bytes** in `animation_clip.json`,
  and publishes atomically (no overwrite).
- `animation_clip_preview_current(handlers, workflow_id, preview_dir, clip_path, animation_dir)`
  resolves live evidence bindings, requires the upstream preview and source clip file to remain
  current, and checks that the clip preview package matches deterministic manifest and file
  bytes implied by that snapshot (not caller-rehashed tampering). Stale evidence, upstream
  preview, or source clip returns `False`; invalid layouts raise typed validation/currentness
  errors.

The export layer performs no database writes, provider calls, or Blender/Godot work.

```python
from gamefactory.workflows.v08_candidate_preview import export_rigged_character_candidate_preview
from gamefactory.workflows.v08_candidate_animation_clip_preview import (
    animation_clip_preview_current,
    export_rigged_character_animation_clip_preview,
)

preview = export_rigged_character_candidate_preview(handlers, workflow_id, "preview-out")
clip_preview = export_rigged_character_animation_clip_preview(
    handlers,
    workflow_id,
    preview.preview_root,
    "clips/arm_wave_01.json",
    "clip-preview-out",
)
assert animation_clip_preview_current(
    handlers,
    workflow_id,
    preview.preview_root,
    "clips/arm_wave_01.json",
    clip_preview.animation_clip_preview_root,
)
```

## Package layout

Exactly these files (no extras):

| File | Role |
|------|------|
| `character.glb` | Unchanged bytes from upstream V0.8-4 preview |
| `character.tscn` | Unchanged bytes from upstream V0.8-4 preview |
| `candidate.json` | Unchanged upstream preview envelope |
| `collider.json` | Unchanged upstream collider metadata |
| `preview-manifest.json` | Unchanged upstream preview manifest (hash bound in clip manifest) |
| `animation_clip_preview.tscn` | Instanced `character.tscn` + `AnimationPlayer` with runtime clip builder |
| `animation_clip_preview_player.gd` | Bounded IO, SHA binding, closed clip validation, track build |
| `animation_clip.json` | Original authored clip bytes (not re-serialized) |
| `animation_clip_manifest.json` | Deterministic binding to workflow, C2 triplet, upstream manifest hash, `clip_sha256`, file digests |
| `project.godot` | Minimal compatibility renderer (`run/main_scene` → `animation_clip_preview.tscn`) |

`animation_clip_manifest.json` is not readiness authority; live readiness, upstream preview
currentness, and source clip bytes win on `animation_clip_preview_current`.

The scene-authored `expected_clip_sha256` on `AnimationPlayer` must match manifest
`clip_sha256` and the SHA-256 of the raw `animation_clip.json` bytes. The export also
embeds `verified_weighted_bone_names` (positively weighted contract joints from the
preview GLB, not all twelve names). The Godot consumer rejects clip tracks that target
bones outside that set.

Copy the package into a separate Godot consumer project before import or inspection.
Godot creates import/cache files. Integration tests consume such a copy.

## Godot consumer behavior

- **Bounded reads**: clip and manifest files are read with a `MAX+1` byte cap; size growth,
  truncation, or oversize payloads fail before JSON parse.
- **Closed clip shape**: exactly five top-level keys; `clip_id` matches `[A-Za-z][A-Za-z0-9_]{0,63}`;
  `duration_seconds` finite in `[0.001, 10]` (Godot adapter minimum); unit quaternions within
  `1e-5`; tracks/keyframes bounded and strictly ordered.
- **Skeleton contract**: twelve internal-skin bone names present; `SM_HumanoidSkin` binds to the
  skeleton actually used for tracks.
- **Autoplay**: the trusted `arm_wave_01` fixture (1.5s) builds and plays on load when bindings
  are valid.

Arbitrary valid no-op clips are not required to deform the mesh; only the trusted acceptance
fixture and the pinned minimum-duration probe assert baked deformation.

## Tests

- Unit: `tests/unit/test_v08_candidate_animation_clip_preview.py` (completed C2-B managed fixture).
- Integration: `tests/integration/test_v08_candidate_animation_clip_preview_real_tools.py`
  (real Blender + Godot when `GAMEFACTORY_TEST_BLENDER` / `GAMEFACTORY_TEST_GODOT` are set).

The trusted acceptance fixture clip is `arm_wave_01` (1.5s, non-looping, `LeftUpperArm` Y 30°
at 0.75s plus a `Spine` identity track). Rendered inspection harness (not shipped in the
package): `src/gamefactory/resources/v08_candidate/animation_clip_preview_inspect.gd`.

Import may run headless, but deformation inspection requires the real compatibility
renderer and `--audio-driver Dummy`. The inspector validates autoplay, track contract, seeks
at 0 and 0.75s, and the same affected/unaffected baked vertex oracle used for V0.8-5 acceptance.

**Minimum-duration probe** (separate from the 1.5s fixture): pass `--gf-min-duration-probe` as a
Godot user argument when running the inspect script against a package whose `animation_clip.json`
is the pinned `0.001s` `min_len_probe` document. The probe checks `Animation.length`, explicit
`seek` at `0`, `0.0005`, and `0.001`, and left-arm deformation without requiring `is_playing`
after frames (the clip may finish in fewer than three frames). Python export accepts clips up to
`10.0s`; the main integration path still proves `1.5s` acceptance.

## Limits

- Local clip JSON is limited to 64 KiB and 32 nested containers. A linear,
  string-aware check enforces nesting before deserialization, independently of
  the Python interpreter's recursion limit. Strict JSON and schema checks still
  apply; valid clip bytes and hashes are preserved.
- The engine-independent parser accepts `0 < duration_seconds <= 10`; the Godot
  exporter rejects durations below `0.001` before staging, without changing the
  source bytes or key times.
- Source drift after atomic publication can leave an immutable stale directory.
  Export fails and does not delete that published directory.
- Orphan or stale clip preview directories are not auto-healed; `animation_clip_preview_current`
  returns `False` when bindings drift.
- The manifest records digests but does not override scene-authored `expected_clip_sha256`.
- Weighted-bone capability is derived from decoded vertex weights at export time; unweighted
  contract joints are excluded from `verified_weighted_bone_names`.
