# 10. MESHY GERÇEK ÜCRETLİ ÇAĞRI GÜVENLİĞİ

Bu sprint ilk gerçek paid generation içerebilir.

Bu nedenle kurallar katıdır.

Gerçek paid operation yalnız:

1. Asset spec valid.
2. Concept artifact valid.
3. Concept approved.
4. Paid operation approved.
5. Budget policy permits operation.
6. Idempotency fingerprint persisted.
7. Provider invocation intent durably persisted.

olduktan sonra başlayabilir.

Paid request gönderilmeden hemen önce:

```text
provider
operation
asset revision
concept hash
request fingerprint
approval id
estimated cost
```

kalıcı kayda alınmalıdır.

Provider task ID döner dönmez durable state'e yaz.

Process/CLI ölürse:

```text
task ID biliniyor
→ provider query/resume

task ID bilinmiyor fakat request gönderilmiş olabilir
→ UNCERTAIN
→ otomatik ikinci paid generation YOK
```

Exactly-once garantisi iddia etme.

Duplicate-resistant davranışı kanıtla.
