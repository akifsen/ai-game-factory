# V0.7 profile catalog boundary

The legacy asset profile catalog remains the default. `builtin_registry()`
continues to expose the frozen V0.5 profiles and unsupported identifiers used
by existing workflows and golden behavior tests.

V0.7 uses `builtin_v07_registry()`, a separate closed catalog. Its known
profile identifiers are listed as unsupported until each profile completes its
release gates. V0.7 specification parsing and the local assembly CLI use this
catalog by default; neither path falls back to a legacy profile lookup.

Operators can inspect the catalogs separately:

```text
gamefactory asset profiles
gamefactory asset profiles --contract-version 0.7.0
```

The first command retains the existing output. The second reports current V0.7
availability. It does not activate candidate profiles or accept caller-supplied
profile files.
